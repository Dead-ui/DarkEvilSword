# Тропа героя

Мини-квест на Python в консоли. Один уровень: три моба, торговец и босс.
Перед началом игрок вводит имя и выбирает класс. У каждого класса —
своё оружие, свои умения и свой стиль боя.

## Запуск

Нужен Python 3.8 или новее. Никаких сторонних библиотек.

```bash
cd hero_quest
python3 main.py
```

На Windows:

```bash
python main.py
```

## Как играть

Всё управление — цифрами:

- `1` — обычная атака;
- `2` — умение (откроется список умений класса);
- `3` — зелье (здоровья или маны);
- `0` — назад / уйти из лавки.

Атака, умение и зелье занимают один ход. После хода героя атакует враг.

### Умения

**Воин**
- «Мощный удар» — 12 маны, урон x1.8.
- «Боевой клич» — 15 маны, +8 к атаке до конца боя.
- «Второе дыхание» — 20 маны, восстановить 35% HP.

**Маг**
- «Огненный шар» — 18 маны, урон x2.1.
- «Ледяная стрела» — 22 маны, урон x1.4 и враг пропускает ход.
- «Исцеление» — 28 маны, восстановить 40% HP.

**Стрелок**
- «Точный выстрел» — 12 маны, урон x1.7, шанс крита 35%.
- «Двойной выстрел» — 16 маны, два попадания по 0.9x.
- «Ядовитая стрела» — 14 маны, урон x0.8 и яд (6 урона, 3 хода).

**Ассасин**
- «Удар в спину» — 12 маны, урон x2.0, шанс крита 25%.
- «Дымовая завеса» — 14 маны, уклонение от следующей атаки.
- «Отравленный клинок» — 16 маны, урон x1.0 и сильный яд (8 урона, 3 хода).

## Магазин

Лавка встречается в деревне и после каждого побеждённого моба.

- Зелье здоровья — 25 золота, восстанавливает 45% HP.
- Зелье маны — 20 золота, восстанавливает 50% MP.
- Оружие — 3 варианта на каждый класс. Купленное оружие можно
  переключать бесплатно: сила оружия прибавляется к атаке.

Стартовые деньги — 50 золота. Золото выпадает с мобов и босса.

## Противники

1. **Лесной гоблин** — 55 HP, лёгкая разминка.
2. **Волк-альфа** — 78 HP, бьёт сильнее.
3. **Разбойник из чащи** — 98 HP, крепкая защита.
4. **Босс: Горток, король гоблинов** — 200 HP. Каждый третий ход
   применяет «Королевский удар» с повышенным уроном.

После каждого моба герой отдыхает: +25% HP и +40% маны.

## Боевая система

- Урон = атака с учётом оружия и бонусов минус 60% защиты цели,
  плюс случайный разброс ±10%.
- Обычная атака имеет 10% шанс критического удара (x1.5).
- Яд наносит фиксированный урон в начале хода врага.
- Лёд заставляет врага пропустить ход.
- Уклонение полностью блокирует одну атаку.
- Эффекты «клича» и «уклонения» сбрасываются в начале нового боя.

## Где что менять

Всё лежит в `main.py`:

- `WEAPONS` — оружие, его бонус и цена;
- `CLASSES` — характеристики классов и умения;
- `HEALTH_POTION_PRICE`, `MANA_POTION_PRICE`, `HEAL_PCT`, `MANA_PCT` — магазин;
- `make_mobs()` и `make_boss()` — враги, их HP, атака и награда;
- `roll_damage()` — формула урона.
